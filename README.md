# polar-projections

A set of notebooks illustrating a technique for reconstructing EUV polar views. We reproject one rotation of EUV data into a native polar view, collecting a minimum intensity map along the way. This technique minimizes obfuscation of overlying plasma material, better constraining polar coronal hole boundaries.
